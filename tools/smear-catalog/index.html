01

What it is

In one line

A smear frame is the one drawing where an animated object stops being itself to show how fast it moves. The catalog puts seven ways of drawing it next to each other, on the same motion, so you can pick one by eye.

The techniques
  • Squash and StretchThe shape stretches along its path with speed and thins as it does; it flattens against what it hits.
  • ElongateThe middle of the object runs along the path it just covered while its ends keep their shape.
  • Motion blurA camera shutter: the object averaged over the path it travels while the shutter is open.
  • Smudged blursThe back of the object dragged into soft streaks of its own colours.
  • Jagged linesThe back torn into a zigzag along the path, with the torn edge outlined.
  • Sketched gesturesQuick pencil strokes along the motion, each in the colour of the spot it starts on.
  • SpeedlinesComic-strip lines over the object and its path, with cuts through its front.
How it works

Every effect reads the object's silhouette and its own colours, and follows the path it actually travelled, so on an arc the smear curves. The object can be a ball, a word, an icon or any image you drop in.

Six looping paths: A-B-A, enter and exit, a throw, a swing, into a wall, a drop with anticipation. The animation runs at 30 fps, on threes by default; every effect is redrawn with each drawing. Settings are in seconds, so an effect looks the same at any frame rate.

How to use it

In the catalog
  • Pick a path and a speedIn the header. The speed changes the moves and the anticipation, never the pauses.
  • Change the object and the drawingsUnder ⚙: the object, how many frames each drawing is held, squash and stretch on or off.
  • Open a technique⚙ Settings on a tile: step through it frame by frame, see every drawing of the cycle as a storyboard, tune its settings. The tile keeps them.
Files
  • index.htmlThe catalog: header, grid of loops, preview with storyboard and settings.
  • smear-effects.jsThe smear effects, each with its defaults and settings.
  • smear.jsSprites, silhouettes, poses, squash and stretch, the track behind the object.
  • core.jsEasing, seeded randomness and other motion basics.
Source
